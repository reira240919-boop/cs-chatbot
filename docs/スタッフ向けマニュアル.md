# スタッフ向けマニュアル

ボタニカ お問い合わせ対応（スタッフ用の画面）の使い方です。

AI が先にお客様へ返事をします。AI が答えられないときや、クレーム・返品などのときは、スタッフに引き継がれます。スタッフは、引き継がれた会話に返信します。

---

## 1. ログイン

1. ブラウザで https://cs-chatbot-pi.vercel.app/operator を開く
2. メールアドレスとパスワードを入れて「ログイン」

ブックマークしておくと便利です。終わるときは、右上の「ログアウト」を押します。

---

## 2. 画面の見方

| 場所 | 中身 |
| --- | --- |
| 上の切りかえ | 「お問い合わせ」（会話の対応）と「よくある質問」（AI が使う FAQ）。今いる方に色が付きます |
| 左の一覧 | 会話の一覧。新しいメッセージが来ると、開き直さなくても上に出ます |
| 一覧の上のタブ | **スタッフ待ち**（返信が必要）／**対応中**／**すべて** |
| 右 | 選んだ会話の中身と、返信の欄 |

- ブラウザのタブに **「(2) スタッフ待ち」** のように数が出ているときは、返信を待っているお客様がいます。
- 会話の札の意味：

| 札 | 意味 |
| --- | --- |
| AI 対応中 | AI が返事をしています。スタッフは何もしなくて大丈夫です |
| スタッフ待ち | AI から引き継がれました。**返信が必要です** |
| スタッフ対応中 | スタッフが担当しています。AI は返事をしません |
| 終了 | 対応が終わった会話です |

---

## 3. 対応のしかた

1. 「スタッフ待ち」のタブから、会話を選ぶ
2. AI とのやりとりを読んで、内容を確かめる
3. 右上の **「対応する」** を押す
   - あなたの担当になり、ほかのスタッフにも「担当 〇〇」と出ます
   - 返信を送るだけでも、自動であなたの担当になります
4. 下の欄に返信を書いて送る
   - **Enter で送信、Shift + Enter で改行**
   - 送ると「送信しました」と出て、お客様の画面にすぐ届きます
5. 解決したら、右上の **「終了にする」** を押す
   - 確認が出ます。終了にすると、その会話には返信できなくなります
   - お客様がそのあとまた送ってきたときは、新しい会話として一覧に出ます

---

## 4. 営業時間外（18 時〜翌 10 時）

- その時間も AI は返事をします。
- AI が引き継いだ会話には「翌営業日にスタッフからご返信します」と案内しています。
- 朝いちばんに「スタッフ待ち」のタブを見て、順に返信してください。

---

## 5. 過去の会話を探す

一覧の上の検索欄を使います。

- **言葉で探す**：言葉を入れて Enter（または「探す」）。お客様・AI・スタッフ、どのメッセージに入っていても見つかります（例：「割れ」「解約」）
- **分類で探す**：「すべての分類」から、在庫・配送・返品・商品質問・その他 を選ぶ
- 元の一覧に戻すときは「検索をやめる」
- 終了した古い会話は、「すべて」タブのいちばん下の「終了した会話をもっと見る」で続きが出ます

お客様はお名前を入れずに使うので、「お客様 #1a2b」のような番号で表示されます。お名前では探せません。

---

## 6. 困ったとき

| こんなとき | すること |
| --- | --- |
| 新しいメッセージが出てこない | ページを開き直す（再読み込み） |
| 「送信できませんでした」と出る | もう一度送る。続くときは開き直す |
| ログインできない | 入力をもう一度確かめる。だめなときは開発担当へ |
| 同じ質問が何度も来る | 「よくある質問」に足すと、次から AI が答えます（[FAQ 編集ガイド](FAQ編集ガイド.md)） |
| スタッフを増やしたい・減らしたい | 開発担当へ依頼する（画面からは追加できません） |
